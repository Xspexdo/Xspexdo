### 👨‍💻 About Me / แนะนำตัว

สวัสดีครับ! ผมชื่อ **Xspexdo** ยินดีต้อนรับสู่หน้า GitHub ของผม 🚀
- 🎧 **Music & Sound:** โปรดิวเซอร์เพลง Beatmaker และผู้พัฒนาเครื่องมือซอฟต์แวร์สนับสนุนการทำเพลง
- 🇹🇭 **Open Source Contributor:** ผู้ริเริ่มและพัฒนา [FL Studio Thai Language Mod](https://github.com/Xspexdo/FL-Studio-Thai-Mod) ม็อดภาษาไทยสำหรับโปรแกรม FL Studio แบบโอเพนซอร์สแจกฟรี 100%
- 💻 **Software & Automation:** พัฒนาโปรแกรม Desktop Application (CustomTkinter / Python), Discord Bots, สคริปต์อัตโนมัติ และเซิร์ฟเวอร์
- 🎯 **เป้าหมาย:** สร้างสรรค์เครื่องมือและซอฟต์แวร์ที่ช่วยให้ทุกคนทำเพลงและใช้งานคอมพิวเตอร์ได้อย่างมีประสิทธิภาพและสนุกขึ้น
